# Unutmamam Gerekenler

React ve Tailwind CSS ile yaptığım hatırlatıcı uygulaması.

## Özellikler
- Hatırlatıcı ekleme
- Hatırlatıcıları listeleme
- Tamamlandı olarak işaretleme (güncelleme)
- Hatırlatıcı silme
- LocalStorage ile verilerin kalıcı saklanması

## Kullanılan Teknolojiler
- ReactJS
- Tailwind CSS
- LocalStorage
